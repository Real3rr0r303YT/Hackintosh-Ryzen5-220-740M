Hackintosh on the ASUS V500
Ryzen 5 220 · Radeon 740M

Scripts that build a ready-to-boot OpenCore EFI for the ASUS V500 Mini Tower (VM501MH / PM500MH) and write a macOS Tahoe installer stick, straight from Windows.

⬇ Download project (ZIP) View on GitHub GPU driver fork (RadeArc)

No pre-built EFI is offered: the scripts download every kext from its official source and generate your own serial numbers.

Quick start

Before you start: back up your data and save your BitLocker recovery key (aka.ms/myrecoverykey). Changing Secure Boot can ask for it.
  1. Download the project ZIP above and unpack it to Documents\Hackintosh-Ryzen5-220-740M.
  2. Build the EFI (downloads OpenCore + kexts, generates your serials): 
    powershell -ExecutionPolicy Bypass -File scripts\Build-EFI.ps1 -Target Hardware -NewSmbios -DebugOpenCore
  3. Get macOS Tahoe recovery from Apple (needs Python): 
    cd build\tools\macrecovery
python macrecovery.py -b Mac-CFF7D910A743CAAF -m 00000000000000000 -os latest -o ..\..\recovery\com.apple.recovery.boot download
  4. Write the USB stick (admin PowerShell, erases the stick, USB disks only): 
    powershell -ExecutionPolicy Bypass -File scripts\New-UsbInstaller.ps1 -DiskNumber 1
  5. BIOS (Del, then F7): Boot → Secure Boot → OS Type = Other OS, Fast Boot = Disabled. See BIOS.md.
  6. Boot the stick with F8 → “UEFI: USB Flash Disk” → “RECOVERY (dmg)” starts automatically.
