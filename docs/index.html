Quick start

From Windows to the macOS installer

Back up your data and save your BitLocker recovery key (aka.ms/myrecoverykey) before changing Secure Boot.
1

Download

Get the project ZIP and unpack it to Documents\Hackintosh-Ryzen5-220-740M.

2

Build the EFI

Downloads OpenCore + kexts and generates your serial numbers.

powershell -ExecutionPolicy Bypass -File scripts\Build-EFI.ps1 -Target Hardware -NewSmbios -DebugOpenCore
3

Get the macOS Tahoe recovery

Straight from Apple with macrecovery (needs Python).

cd build\tools\macrecovery
python macrecovery.py -b Mac-CFF7D910A743CAAF -m 00000000000000000 -os latest -o ..\..\recovery\com.apple.recovery.boot download
4

Write the USB stick

Admin PowerShell. Erases the stick, only accepts USB disks.

powershell -ExecutionPolicy Bypass -File scripts\New-UsbInstaller.ps1 -DiskNumber 1
5

BIOS

Del → F7 → Boot → Secure Boot → OS Type = Other OS, Fast Boot = Disabled.

6

Boot

F8 → “UEFI: USB Flash Disk” → “RECOVERY (dmg)” starts automatically.

Install

Installing macOS, GPU and the boot loader

1

Build the installer EFI

Hardware EFI with the Wi-Fi fix and the graphical picker, no GPU driver. Recovery has Wi-Fi with it, so the normal online install works.

powershell -ExecutionPolicy Bypass -File scripts\Build-EFI.ps1 -Target Hardware -DebugOpenCore -NoBluetooth -OutName EFI-usb
2

Write it to the stick

Admin PowerShell. Keeps the recovery and also copies the gpu folder (RadeArc package + install scripts) onto the stick's RECOVERY partition.

powershell -ExecutionPolicy Bypass -File scripts\New-UsbInstaller.ps1 -DiskNumber 1 -UpdateEfi -Source build\EFI-usb
3

Install macOS

Reinstall from Recovery over Wi-Fi, or offline from InstallAssistant.pkg (OFFLINE-INSTALL.md).

4

OpenCore onto the SSD

Copies EFI\OC next to Windows on the internal EFI partition (backup first) and puts “OpenCore” first in the boot order. No stick needed after that; undo with -Remove.

powershell -ExecutionPolicy Bypass -File scripts\Install-EfiToDisk.ps1 -Source build\EFI-GPU-accel
5

GPU acceleration

In macOS, booted with EFI-GPU-accel. Stage 1 (Metal for apps) installs now; after the next boot stage 2 (desktop on the GPU, Liquid Glass) installs itself and shows the result in a dialog. See GPU.md.

bash /Volumes/RECOVERY/gpu/install-gpu.sh
